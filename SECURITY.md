# Security Policy

## Supported Versions

We actively support the latest version on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < 1.0   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of open-cvbaba seriously. If you believe you have found a security vulnerability, please report it responsibly:

1. **Do not create a public GitHub issue** for security vulnerabilities.
2. Report the vulnerability privately via GitHub Security Advisories or by emailing the project maintainer, [ialim0](https://github.com/ialim0).
3. Please include:
   - A clear description of the vulnerability.
   - Steps to reproduce or proof-of-concept code.
   - The affected component (frontend, backend, Docker configuration, etc.).
   - Potential impact of the vulnerability.

We will acknowledge your report promptly, investigate the issue, and release a fix as soon as possible.
