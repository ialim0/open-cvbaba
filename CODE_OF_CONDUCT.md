# Code of Conduct

## Our standard

We want open-cvbaba to be a welcoming, constructive, and inclusive project. Participants should communicate with respect, assume good faith, and focus criticism on ideas and code rather than people.

Unacceptable behavior includes harassment, discrimination, personal attacks, intimidation, deliberate disruption, and publishing private information without consent.

## Enforcement

Report concerns to the repository maintainer, [ialim0](https://github.com/ialim0), through the project's GitHub contact or a private GitHub report. Reports will be handled as confidentially as practical. The maintainer may remove comments, close discussions, or restrict participation when necessary to protect the community.
